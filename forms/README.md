# Формы

Формы на сайте [UnicoreCMS]: заявки в команду, заявки на разбан, жалобы на игроков, баг-репорты,
обратная связь. Форма собирается в панели из полей, получает свой адрес на сайте, а заполненные
заявки разбираются во «Входящих».

| | |
| ------ | ------ |
| Идентификатор | `forms` |
| Контракт | `^1.7.0` |
| Страницы сайта | `/mod/forms`, `/mod/forms/<адрес>`, «Мои заявки» во вкладках кабинета |
| Страницы панели | «Формы → Конструктор», «Формы → Заявки» |
| Таблицы | `mod_forms_forms`, `mod_forms_fields`, `mod_forms_submissions` |

## Что умеет

- Шесть заготовок: заявка в команду, заявка на разбан, жалоба на игрока, баг-репорт, обратная связь
  и пустая форма
- Девятнадцать типов полей: строка, текст, число, почта, ссылка, список, несколько из списка,
  переключатели, галочки, да или нет, дата, шкала, оценка, сервер, файл, заголовок, абзац,
  разделитель
- Поля в половину ширины и условия показа: поле появляется, только когда ответ на другое поле
  подходит под условие
- Правила приёма: только для авторизованных, право на отправку, одна заявка на человека, повтор
  через N часов, предел числа заявок, окно приёма по датам, свой текст при закрытом приёме
- Гость оставляет имя и почту для ответа — иначе связаться с ним будет нечем
- Разбор заявок: статусы «Новая», «На рассмотрении», «Принята», «Отклонена» и ответ автору
- Уведомления: новая заявка уходит в выбранные каналы вебхуков, решение — письмом автору
- Переводы: заголовки, поля и тексты формы переводятся в редакторе локализации
- Ночная чистка: рассмотренные заявки старше заданного срока удаляются в 4 часа

## Права

| Право | Что открывает |
| ------ | ------ |
| `mod.forms.read` | Смотреть формы и заявки |
| `mod.forms.write` | Создавать формы, править поля, правила и настройки приёма |
| `mod.forms.review` | Менять статус заявки и отвечать автору |

## Настройки

Страница «Модули» в админке, кнопка настроек у модуля.

| Настройка | По умолчанию | Что делает |
| ------ | ------ | ------ |
| Заголовок страницы форм | Формы | Крупная надпись на `/mod/forms` |
| Подзаголовок страницы форм | Заявки, обращения и всё, что можно заполнить на сайте | Строка под заголовком, можно оставить пустой |
| Хранить рассмотренные заявки, дней | 0 | Через сколько дней удалять принятые и отклонённые заявки. Ноль — хранить всё |

## Установка

Соберите модуль — как, написано в [корневом README](../README.md#сборка), — и поставьте папку
`forms` в `modules/`. Подробнее про формы — в [документации].
