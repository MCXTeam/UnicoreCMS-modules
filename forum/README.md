# Форум

Модуль форума для UnicoreCMS: разделы любой вложенности, темы, ответы, реакции и модерация по ролям.

## Что внутри

- **Разделы.** Вложенность не ограничена в данных, на странице форума показываются два уровня — раздел и его подразделы; всё, что глубже, открывается блоком «Подразделы» на странице раздела. Темы можно заводить в любом разделе.
- **Права.** Четыре общих права (`mod.forum.read`, `write`, `moderate`, `manage`) плюс настройки на каждом разделе: своё право на чтение, своё на запись и список ролей-модераторов. Модератор раздела модерирует и все вложенные в него.
- **Темы.** Закрепить, закрыть, перенести, удалить — модератор; свою тему автор может закрыть и удалить сам.
- **Сообщения.** Редактор с картинками, цитирование, правка с пометкой «изменено», мягкое удаление, реакции набором Fluent Emoji.
- **Непрочитанное.** По темам и разделам. В базе хранятся только отклонения: отметка «всё прочитано» ставит одну дату и стирает построчные отметки.
- **Уведомления.** Ответ в вашей теме и ответ на ваше сообщение приходят в колокольчик; категорию «Форум» игрок может выключить в кабинете.
- **Поиск** по заголовкам тем и тексту сообщений, с учётом прав на разделы.

## Настройки

| Ключ | Что делает |
|---|---|
| `title` | заголовок страницы и подпись пункта в меню сайта |
| `subtitle` | строка под заголовком |
| `nav_order` | место пункта в шапке сайта |

## Сборка

```
pnpm install
pnpm build
```

Иконки реакций лежат в `client/assets/emoji` и вырезаны из [Fluent Emoji Flat](https://github.com/microsoft/fluentui-emoji) (MIT).
Обновить набор: `pnpm emoji` — скрипт берёт иконки из `@iconify-json/fluent-emoji-flat` по списку в `shared/constants.ts`.
