# Команда проекта

Страница состава для [UnicoreCMS]: администрация, модераторы, хелперы. Состав не заводится руками —
модуль собирает его из ролей сайта и привилегий, отмеченных как служебные.

| | |
| ------ | ------ |
| Идентификатор | `team` |
| Контракт | `^1.4.0` |
| Страницы сайта | `/mod/team`, ссылка в меню и в подвале |
| Страницы панели | «Команда проекта» |
| Таблицы | `mod_team_notes` |

## Откуда берутся люди

| Источник | Где отметить | Куда попадает человек |
| ------ | ------ | ------ |
| Роль сайта | «Основное → Роли», флажок «Служебная роль» | В общий раздел: роль сайта не привязана к серверу |
| Привилегия | «E-Commerce → Донат → Группы», флажок «Служебная роль» | В раздел того сервера, где привилегия выдана |

Дальше ничего делать не нужно: выдали человеку роль «Модератор» на сервере — он появился на
странице, срок привилегии истёк — исчез. Один человек может стоять в нескольких разделах.

Подпись под ником — название роли или привилегии, цвет задаётся там же, где и флажок. В панели
к человеку дописывается только строка о том, чем он занимается; она переводится как обычный контент.

## Права

| Право | Что открывает |
| ------ | ------ |
| `mod.team.read` | Смотреть состав в панели |
| `mod.team.write` | Править описание участника |

## Настройки

Страница «Модули» в админке, кнопка настроек у модуля.

| Настройка | По умолчанию | Что делает |
| ------ | ------ | ------ |
| Заголовок страницы | Команда проекта | Крупная надпись на `/mod/team` |
| Подзаголовок | Люди, которые делают проект | Строка под заголовком, можно оставить пустой |
| Заголовок общего раздела | На всех серверах | Так называется раздел с обладателями служебных ролей сайта |

## Установка

Соберите модуль — как, написано в [корневом README](../README.md#сборка), — и поставьте папку
`team` в `modules/`. Подробнее — в [документации].
