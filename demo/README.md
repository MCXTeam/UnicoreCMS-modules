# Демо-модуль

Пример модуля для [UnicoreCMS], на котором видно весь контракт: своя таблица, публичный и закрытый
маршруты, права, настройки, подписка на события, канал вебхука, ночная задача, страницы сайта
и панели, вставки в чужие экраны. Пользы от него нет — он для тех, кто пишет свой модуль.

| | |
| ------ | ------ |
| Идентификатор | `demo` |
| Контракт | `^1.7.0` |
| Страницы сайта | `/mod/demo`, `/mod/demo/cabinet` |
| Страницы панели | «Демо-модуль» |
| Таблицы | `mod_demo_notes` |

## Что где смотреть

| Что показывает | Файл |
| ------ | ------ |
| Манифест: пространства имён, права, настройки, слои | `module.json` |
| Сборка серверной части, `MODULE_EXTERNALS` | `tsup.config.ts` |
| Точка входа: сущности, модули Nest, события, настройки | `server-src/index.ts` |
| Своя таблица | `server-src/entities/note.entity.ts` |
| Публичный маршрут и маршрут под правом | `server-src/demo.controller.ts` |
| Загрузка файла в хранилище ядра | `server-src/demo.upload.controller.ts` |
| Свой канал вебхука | `server-src/demo.channel.ts` |
| Ночная задача | `server-src/demo.tasks.ts` |
| Меню сайта, вкладка кабинета, слоты | `client/plugins/register.ts` |
| Меню панели и вставка в карточку игрока | `admin/plugins/register.ts` |
| Строки модуля и названия прав | `locales/ru.json` |

## На что подписан

Каждое событие модуль записывает заметкой в свою таблицу — так видно, что ядро действительно
зовёт обработчики.

`core.ready` · `user.registered` · `user.login` · `user.password.changed` · `payment.paid` ·
`purchase.completed` · `gift.activated`

## Куда встраивается

| Место | Что появляется |
| ------ | ------ |
| Меню сайта | Пункт «Демо-модуль» |
| Вкладки кабинета | Вкладка «Демо-вкладка» |
| Страница сервера | Виджет модуля |
| Страница новости | Блок под текстом |
| Подвал сайта | Строка со ссылками |
| Карточка игрока в панели | Заметки о нём |

## Права

| Право | Что открывает |
| ------ | ------ |
| `mod.demo.read` | Смотреть заметки |
| `mod.demo.write` | Добавлять заметки и загружать файл |

## Настройки

Страница «Модули» в админке, кнопка настроек у модуля.

| Настройка | По умолчанию | Что делает |
| ------ | ------ | ------ |
| Приветствие | Привет | Текст здоровается с игроком на странице модуля |
| Лимит заметок | 10 | Сколько последних заметок показывать: от 1 до 100 |

## Установка

Соберите модуль — как, написано в [корневом README](../README.md#сборка), — и поставьте папку
`demo` в `modules/`. Что означает каждая часть модуля — в [документации].

[документации]: https://docs.unicorecms.ru/docs/extensions/module
